# Moeslim PM: Brand Kit

Identitas: **Moeslim PM: Personal & Mosque**

Paket ini adalah **redraw vektor yang konsisten** berdasarkan konsep logo utama yang dipilih: **lengkung mihrab + kubah masjid + buku Al-Qur'an terbuka + bulan sabit emas**. Karena gambar konsep awal berupa board raster, ini bukan hasil ekstraksi path asli dari gambar generatif.

## Struktur file

- `SVG/`: logo utama, logo bertumpuk, simbol, wordmark, versi monokrom, ikon aplikasi, serta adaptive foreground.
- `PNG/Logo/`: logo transparan beresolusi tinggi.
- `PNG/Icon/`: simbol transparan dan ikon aplikasi dengan latar warna.
- `Favicon/`: `favicon.ico`, `favicon.svg`, ukuran PNG, Apple touch icon, dan `site.webmanifest`.
- `Android/`: raster ikon Android multi-density, adaptive foreground & background, dan ikon Play Store 512.
- `Preview/`: preview branding.
- `Panduan/`: palet, cara memakai aset, dan kode HTML favicon.

## Logo resmi

Nama lengkap: **Moeslim PM**
Subjudul: **Personal & Mosque**

Untuk Google Play gunakan `Android/play_store_icon_512x512.png`. Untuk ikon launcher Android, gunakan file pada folder `Android/`, termasuk pasangan adaptive icon. Untuk website gunakan aset dalam `Favicon/` dan kode di panduan.

## Palet
- Emerald: `#087E65`
- Deep green: `#07372F`
- Dark green: `#06473D`
- Gold: `#D9AB36`
- Cream: `#F7F7F1`

Font yang disarankan: **Inter**. File font tidak disertakan dalam ZIP. SVG wordmark tetap editable sehingga sistem dapat mengganti ke font serupa jika Inter belum terpasang.

## Catatan desain

Logo ini adalah karya interpretasi dari konsep visual sebelumnya. Bentuk geometri telah dirapikan untuk kebutuhan format SVG, favicon, dan launcher. Lakukan pengecekan keunikan merek dan kemiripan dengan merek terdaftar sebelum pengajuan merek resmi.
